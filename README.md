# 🎓 Student Registration System

A modern Student Registration System built with **ASP.NET Core MVC**, **C#**, **Razor Views**, **Entity Framework Core**, and **SQL Server**.

This project demonstrates a complete CRUD-based web application where users can create, view, edit, search, and delete student records.

---

## 🚀 Features

- ✅ Student Registration
- ✅ View Student List
- ✅ Student Details
- ✅ Edit Student Information
- ✅ Delete Student Records
- ✅ Search Students
- ✅ Server-Side Validation
- ✅ Razor Views
- ✅ ASP.NET Core MVC Architecture
- ✅ Entity Framework Core
- ✅ SQL Server / LocalDB
- ✅ Responsive Modern UI
- ✅ CRUD Operations
- ✅ Anti-Forgery Protection
